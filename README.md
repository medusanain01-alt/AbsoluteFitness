# Absolute Fitness

A responsive, browser-based admin dashboard for tracking gym enrolments.

## Getting started

Open `index.html` in a modern browser. No build step or package installation is needed.

## Features

- Add enrollees with their name and phone number, choosing a 15- or 30-day plan, with or without a 3- or 7-day bonus promo.
- Automatically set 15-day plan prices to ₱400 and 30-day plan prices to ₱750; promo days are added at no extra charge.
- Track the full membership duration, including any promo days.
- Automatically set the plan price to ₱400 for 15 days or ₱750 for 30 days.
- Track start date, end date, days remaining, and active, expiring, or expired status.
- Search and filter the enrollee directory.
- View enrolment counts and recorded plan value on the dashboard.

Enrolments are stored in the browser's local storage on the device where the dashboard is opened. They are not synced to other devices or backed up to a server.
